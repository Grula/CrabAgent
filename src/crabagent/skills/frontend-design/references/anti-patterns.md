# Defaults That Read as Machine-Made

A filter, not a style. Any one of these can be fine on purpose; stacking several is what makes a
page look generated on sight. If the user asks for one of them, do what they ask.

## Color and surface

- Purple / indigo / violet accent, or a purple-to-blue hero gradient — the most common tell.
- Gradient-filled headline text (`background-clip: text`).
- Warm cream (`#faf8f4`-ish) as the whole page background with a serif display and terracotta
  accent, used by reflex.
- Near-black page with a single acid-green or vermilion pop, used by reflex.
- Aurora blobs, glowing colored shadows, or the same glow on every card.
- Glassmorphism (blur + border + shadow) on every surface.
- Body text in light grey (Tailwind gray-400/500 territory) that fails contrast.

## Type

- One family everywhere, especially Inter, or leaning on a single trendy face (Geist, Space
  Grotesk, Instrument Serif, Roboto, Arial) as the whole identity.
- One weight and size throughout — no hierarchy.
- Tracked all-caps micro-labels above every section.
- A long (8+ words), huge (48 px+) headline that says nothing specific.

## Layout and components

- Centered hero: eyebrow pill + headline + two buttons.
- The three-card feature grid, each with an icon in a rounded square.
- Bento grids for everything.
- The same eyebrow → headline → three cards section repeated down the page.
- Everything centered.
- One radius (`rounded-2xl`) on every element.
- Left-border accent stripes on cards, colored borders on rounded boxes, cards inside cards.
- Numbered markers (01 / 02 / 03) on content that isn't a sequence.

## Decoration and motion

- Emoji as feature icons or section markers.
- Hover "lift" (`scale(1.05)`) on every card.
- Fade-up / slide-up on every element as it scrolls in.
- Motion that ignores `prefers-reduced-motion`.
- Hand-drawn squiggles or mascots with no purpose.

## What to do instead

Return to the subject: what materials, instruments, documents and vocabulary belong to its world?
Choose type, color and layout from there, put boldness in one place, and keep everything around
it quiet.
